# 問AI・智慧港口 版本 C 設計企劃(Planning,未實作)

> 依 PO feedback 規劃:A 版閱讀量太大 → C 版走 **Duolingo 式圖像化、低文字、高互動**;
> E3 加重 **生成式 AI(LLM 文字 + 生圖)** 的接受/修正/退回;B 版棄用(離港口情境太遠)。
> 本文件只是企劃,review 通過後才動工;其他模組 C 版將沿用同一套原則。

---

## 1. 設計原則(全 C 版通用)

| 原則 | 具體做法 |
|---|---|
| 一句話原則 | 每題畫面上只有 **一行短指令**(≤15 字),其餘資訊全部圖像化 |
| 圖示取代文字 | 對/錯/修正 → **✅ 綠彈跳 / ❌ 紅搖晃 / ✏️ 黃閃爍** 動畫圖示,不再出現「答對了!」「再想一想」等文字段落 |
| 鷹架縮短 | 答錯時只顯示 **一行提示**(≤12 字)+ 指向關鍵證據的視覺提示(高亮/箭頭),不用完整句子解釋 |
| Duolingo 節奏 | 頂部**進度條**;答對後 **0.8 秒自動進下一題**(不用按「下一題」);連續答對出現 **combo 星星** |
| 對話減量 | Hook 對話每則 ≤3 句、每句 ≤20 字;知識點改由**任務中的圖像體驗**帶出 |
| 語音保留 | 指令與提示照樣 TTS(正式版預錄 MP3),小朋友可以「用聽的」不用讀 |

## 2. 新作答機制(需擴充引擎,共 6 種)

參考 Duolingo 截圖的四種畫面,對應如下:

| 機制 | 玩法 | 對應 Duolingo | 用途 |
|---|---|---|---|
| `imgpick` 圖像四選一 | 「選出正確的圖」:2×2 大圖卡,點選即判定 | Select the correct image | E2 概念題(AI 內部是什麼?) |
| `pairs` 翻牌配對 | 6-8 張卡兩兩配對(迷思 ↔ 破解),配對成功卡片消失 | matching pairs | E2 學習任務 |
| `tokens` 句子拼裝 | 用字塊拼出正確描述:「AI 靠 __ 找出 __」,點字塊上移 | Translate this sentence(字塊) | E2 學習+測驗(正確描述 AI 的語言,正中 E2 Basic) |
| `oxrush` 快問快答 | 說法卡連發,大按鈕 👍/👎 兩擇,10 秒節奏感 | — (快節奏變體) | E2 測驗 |
| `stamp` 三印章 | 生成式 AI 輸出 + 證據卡並排,蓋 ✅/✏️/🚫 大印章,零文字選項 | — | E3 學習+測驗 |
| `spot` 圖片找碴 | AI 生成圖上「點出不合理的地方」(热点點擊) | — | E3 生圖題(手指/腳數量錯誤等) |

引擎另加:進度條、combo 動畫、答對自動前進、錯誤搖晃動畫、任務結尾星星結算(取代文字結語)。

## 3. E2 說明 AI 如何完成任務(破解迷思)

**Hook(阿浪,3 句)**:「大家都說 AI 吊車『會思考』。」「真的嗎?我們打開它的腦袋看看!」

**學習任務「打開 AI 的腦袋」(~6 題,3 種機制輪替)**
1. `imgpick`:吊車裡面其實是?→ 🧠小人圖 / 📊資料流圖 / 🎩魔法帽圖 / 💤睡覺圖(答:資料流)
2. `imgpick`:掃描機「認出」蘋果的方式?→ 👀像人一樣看懂 / 🧩跟學過的圖案比對(兩大圖卡)
3. `pairs` 翻牌:迷思↔破解 3 組(🧠「它會想」↔📊「它在比對規律」/😢「它心情不好」↔🕳️「資料裡沒教過」/📖「它看得懂」↔🧩「它在對圖案」)
4. `tokens`:拼出正確句子「AI 靠 [資料] 學到 [規律]」(干擾塊:魔法、心情)
5. `tokens`:「資料裡 [沒有] 的東西,AI 容易 [出錯]」(干擾塊:全部、變聰明)

**測驗任務「說法快篩」(6 題計分)**
- `oxrush` 4 題:「AI 廣播今天很難過 👎」「導航是比對過去資料 👍」「吊車全部都懂 👎」「沒學過的容易錯 👍」
- `imgpick` 2 題:概念圖選擇

## 4. E3 判斷 AI 輸出:接受・修正・退回(生成式 AI 加重)

**新角色:港口生成式 AI 助理「小海」**(用 AIrobot.png)——會寫廣播稿、回答旅客問題、畫海報,但常出包。
機制以 `stamp` 三印章為主軸:**左邊小海的輸出,右邊證據卡**,學生比對後蓋章,全程幾乎零文字選項。

**Hook(3 句)**:「新同事小海是生成式 AI,一秒寫稿一秒畫圖!」「但它寫的、畫的……都對嗎?」「你的三個印章:✅ ✏️ 🚫!」

**學習任務「小海的作品檢查台」(~6 題)**
| # | 小海的輸出(左) | 證據(右) | 正解 |
|---|---|---|---|
| 1 | LLM 廣播稿:「海豚號 10:00 進港」 | 船班表:海豚號 10:00 ✔ | ✅ |
| 2 | LLM 廣播稿:「海豚號 **3:00** 進港」 | 船班表:10:00 | ✏️(點擊稿中錯誤數字後蓋章) |
| 3 | LLM 回答旅客:「本港有 500 年歷史的美人魚雕像,就在東碼頭!」 | 港口地圖:沒有雕像 | 🚫(AI 會「一本正經地編故事」= 幻覺) |
| 4 | `spot` 生圖:走失小狗協尋海報,狗有 **5 條腿** | 小狗照片:4 條腿 | 先「找碴」點出第 5 條腿 → ✏️ |
| 5 | `spot` 生圖:碼頭安全宣導圖,救生員手有 **6 根手指**、背景船浮在天上 | — | 找碴 2 處 → 🚫 重生成 |
| 6 | 生圖:港口地圖插畫,正確可愛 | 對照實景 | ✅ |

**測驗任務「一日檢查員」(6 題計分)**
- `stamp` 4 題:新 LLM 稿(對的 1、要修的 1、編造的 1)+ 生圖 1
- `spot` 1 題:AI 生圖找碴(文字招牌亂碼)
- `imgpick` 1 題:「小海很有自信地說」→ 一定對嗎?(圖像化二選)

> 保留一點 ML 味:第 3 題幻覺與 E2 的「資料規律」呼應(它在補規律,不是說謊),但比重以生成式 AI 為主。

## 5. Big Idea 收尾(圖像化)

阿浪的大問題改成**三張圖卡擇一**(不是文字段落):
「AI 給的東西,我們該?」→ 🍽️ 全部吞下去 / 🔍✅ 看一看再決定 / 🗑️ 全部丟掉
選 🔍✅ → 小海和阿浪擊掌動畫 + 一句總結;選其他 → 一行提示後再選。
